# Adopters

This file lists organizations using Vald in production or evaluation environment.

We welcome additions of adoption cases. Add an entry to the list below and open a Pull Request.
If disclosing your organization's name is difficult, an anonymous entry (e.g. `A SaaS company`) is fine.

## Adopters List

- **LY Corporation** - Runs Vald as a large-scale ANN search platform in production across a wide range of services:
  - E-commerce - product recommendation and similar-item discovery
  - Advertising - ad recommendation, user targeting, and audience estimation
  - Search - search query refinment and intent detection
  - Media - similar image search and general similarity search
- **National Diet Library** - Powers [JAPAN SEARCH](https://jpsearch.go.jp/) in production:
  - Search - search over digital resources across many fields

## How to Add Your Organization

1. Add an entry to the list above.
2. Include your organization name and a short description or use case.
3. Open a Pull Request following the flow in [CONTRIBUTING.md](https://github.com/vdaas/vald/blob/main/CONTRIBUTING.md).

For questions or consultation about adoption, reach out on [Vald Slack](https://join.slack.com/t/vald-community/shared_invite/zt-db2ky9o4-R_9p2sVp8xRwztVa8gfnPA).
